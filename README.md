## Project Overview

This repository contains the practical assignments completed for the Ethical Hacking and Countermeasures unit. The exercises demonstrate information gathering, network scanning and enumeration, and SQL Injection testing in a controlled environment using Kali Linux and DVWA.

## Assignments Included

1. **Information Gathering (Kenya Red Cross)**
   - WHOIS lookup
   - Host lookup
   - NSLookup
   - TheHarvester
   - WhatWeb

2. **Scanning and Enumeration (Local Kali Linux Machine)**
   - Open port discovery
   - Service version detection
   - Operating system detection
   - Vulnerability assessment using Nmap

3. **SQL Injection Testing**
   - Docker verification
   - DVWA setup
   - SQL Injection demonstration
   - Retrieval of database records
