## Project Overview

This repository contains practical demonstrations, class activities, and hands-on laboratory exercises completed for the Ethical Hacking and Countermeasures course using Kali Linux and DVWA (Damn Vulnerable Web Application).

The activities demonstrate ethical hacking methodologies including reconnaissance, scanning, enumeration, vulnerability assessment, web application testing, and security analysis in a controlled environment.

---

## Weekly Activities

### Week 1 – Information Gathering and Reconnaissance

Tools Used:

* WHOIS
* Host
* NSLookup
* TheHarvester
* WhatWeb

Activities:

* Domain registration lookup
* IP address resolution
* DNS information gathering
* Email and subdomain enumeration
* Website technology identification

### Week 2 – Scanning and Enumeration

Tools Used:

* Nmap

Activities:

* Open port discovery
* Service version detection
* Operating system detection
* Vulnerability assessment using Nmap scripts

### Week 3 – Vulnerable Environment Setup

Tools Used:

* Docker
* Kali Linux

Activities:

* Docker installation verification
* DVWA image deployment
* DVWA container startup and verification

### Week 4 – Web Application Deployment and Configuration

Tools Used:

* Docker
* DVWA

Activities:

* DVWA login configuration
* Database setup and initialization
* Accessing the DVWA home interface

### Week 5 – SQL Injection Testing and Exploitation

Tools Used:

* DVWA

Activities:

* SQL Injection module testing
* Database record retrieval
* Input validation assessment

### Week 6 – Vulnerability Assessment and Scanning

Tools Used:

* Nikto
* Curl
* NVD (National Vulnerability Database)

Activities:

* Nikto installation
* Web server vulnerability scanning
* HTTP header analysis
* CVE vulnerability research

### Week 7 – Web Application Security Testing

Tools Used:

* Browser Developer Tools
* DVWA
* OWASP Top 10

Activities:

* HTTP request analysis
* Cookie security analysis
* Cross-Site Scripting (XSS) testing
* OWASP Top 10 security review
